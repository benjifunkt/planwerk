# Planwerk 1.0.0

The first public release of Planwerk: a calm, local-first app for planning the current week and keeping larger goals in view.

## Downloads

- **Apple Silicon Mac:** choose the file ending in `mac-arm64.dmg`.
- **Intel Mac:** choose the file ending in `mac-x64.dmg`.
- **Windows 64-bit:** choose the file ending in `win-x64.exe`.

## Unsigned preview

This first release is not code-signed yet. macOS Gatekeeper and Windows SmartScreen will therefore show a warning before opening the app. Only download Planwerk from this official GitHub repository.

Automatic updates are included for the Windows installer. They download quietly and are installed when Planwerk is closed. On macOS, Planwerk checks for published versions and links to their GitHub release page. Automatic installation will be enabled in a later signed and notarized release; Mac users of 1.0.0 will need to install that first signed version manually once.
